# Pexels Image Search

Search photos on Pexels and print photo previews and photographer credits.

## Requirements
- Python 3.10 or newer
- Internet connection
- API credential: `PEXELS_API_KEY`

## Setup
1. From the repository root, install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Copy `.env.example` to `.env` in the repository root.
3. Add the API key for this project to `.env`. Never commit `.env`.
4. Run from this folder:
   ```bash
   python main.py
   ```

See the root README for API key registration links and notes.
